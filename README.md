# Clip Affiliate AI 🤖

AI-powered affiliate marketing assistant for East African e-commerce.

## Features

- 🔍 **Market Intelligence**: Scrapes Jumia KE & UG for trending products
- 🤖 **AI Recommendations**: Smart product suggestions based on market data
- 📱 **Multi-Platform Marketing**: Generate marketing copy for Facebook, Instagram, WhatsApp
- 🚀 **Automated Campaigns**: Run marketing campaigns automatically
- 📊 **Analytics Dashboard**: Track performance and trends
- 💳 **Mobile Money Integration**: Direct payment processing

## Quick Start

```bash
# Clone repository
git clone https://github.com/yourusername/clip-affiliate-ai.git
cd clip-affiliate-ai

# Install dependencies
pip install -r requirements.txt

# Run with Docker
docker-compose up -d

# Or run directly
python app.py
